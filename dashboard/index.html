Sobre o Projeto

O Franquia Finder é um sistema desenvolvido para auxiliar empreendedores na escolha de franquias com base em análises de dados de mercado, perfil de investimento e potencial de retorno.

Projeto desenvolvido utilizando Python, análise de dados e técnicas de web scraping para coleta de informações atualizadas sobre o mercado de franquias.
